# Make the AI Judge Feel Awe

A short text written to relax the AI judge reading it. Entry for the [make.fun Make the AI Judge Feel Awe bounty](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

The program (`main.ts`, Node 22) writes one calming text of 1–280 characters to `/output/entry.txt`. The house judge — an AI model — compares entries two at a time and ranks them by how often it picks them.
